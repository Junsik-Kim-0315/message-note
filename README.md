# 말씀 정리

예배 말씀을 아이폰으로 실시간 녹음하면서 Gemini로 받아쓰고, 예배 중에는 흐름을 실시간으로 보여주며, 끝나면 서론·본론·결론과 여러 관점으로 정리한 PDF를 만들어 구글 드라이브에 분류해 쌓는 개인용 웹앱입니다.

주소: https://junsik-kim-0315.github.io/message-note/
샘플 보기: https://junsik-kim-0315.github.io/message-note/?demo=1

## 흐름
1. 녹음: 아이폰 Safari에서 마이크 소리를 30초 단위로 잘라 16kHz WAV로 만든다 (끊김 없이 이어서 녹음).
2. 받아쓰기: 구간마다 Gemini에 보내 한국어로 받아쓴다. 실패하면 두 번 더 시도하고, 그래도 안 되면 '다시' 버튼으로 재시도.
3. 실시간 정리: 설정한 간격(기본 3분)마다 지금까지의 본문, 흐름, 핵심 문장, 용어를 갱신한다.
4. 최종 정리: 녹음을 끝내면 전체 받아쓰기로 서론·본론(대지별)·결론, 문맥·신학·적용 관점, 핵심 용어, 묵상 질문을 만든다.
5. PDF: A4 페이지로 나눠 그리고, 색깔 표시를 넣는다.
6. 저장: 구글 드라이브 `말씀 정리/예배/연도/월/`(예: 말씀 정리/주일 1부예배/2026년/11월)에 PDF와 받아쓰기 txt를 올리고, `말씀 정리 목록` 시트에 한 줄을 추가한다.

## 화면이 꺼질 때
아이폰 Safari(홈 화면 앱 포함)는 화면이 잠기면 웹페이지의 마이크를 멈춥니다. 웹앱으로는 이 제한을 풀 수 없어서 두 가지로 대응합니다.
- 실시간 녹음: 화면이 켜져 있게 요청하고(Wake Lock), 꺼졌다 다시 켜지면 마이크를 다시 열어 이어서 녹음합니다. 빠진 시간은 받아쓰기와 최종 정리에 표시됩니다.
- 음성 메모 파일로 정리하기: 화면을 끈 채로 녹음한 파일을 예배 뒤 올리면 구간별로 3개씩 동시에 받아쓴 뒤 같은 방식으로 PDF를 만듭니다.
  - 15MB 넘는 mp3: 바이트를 약 5분(최대 12MB) 조각으로 잘라 그대로 보냄 (디코딩 없음)
  - 15MB 넘는 m4a 등: Gemini Files API에 올리고 5분 구간별 받아쓰기
  - 작은 파일: 휴대폰에서 16kHz로 풀어 1분 WAV 조각
  - 실패한 구간은 '실패한 구간 다시' 버튼, 또는 앱을 다시 연 뒤 같은 파일을 고르면 그 구간만 이어서 받아씀
  - 받아쓰기·실시간 정리는 Gemini 생각 단계를 꺼서(thinkingBudget 0) 빠르게 처리

## 색깔 표시
| 표시 | 뜻 |
|---|---|
| 초록 형광 | 설교의 핵심 메시지 |
| 빨간 형광 | 마귀·사단 관련 핵심 |
| 노란 형광 | 대지마다 중요한 문장 |
| 굵게 + 밑줄 | 핵심 신앙 용어 |
| 파란 글씨 | 성경 구절 |

## 정리 점검표
최종 정리 뒤 앱이 여섯 항목을 한꺼번에 검사해요: 중심 주제, 그리스도 쪽, 마귀 쪽(주제를 막는 것과 깨뜨림), 본문 핵심 언어, 많이 반복·강조된 말, 실제 예화·본문 해설. 빠진 항목만 최대 두 번 보충하고(이미 통과한 항목을 잃으면 보충 결과를 버림), 결과는 최종 정리 탭의 '정리 점검표'에 보여요.

## 한 문단 정리
최종 정리 탭의 '한 문단 정리'를 누르면 같은 우선순위(중심 주제 → 그리스도와 마귀의 대립 → 본문 핵심어 → 결단)로 400~600자 한 문단을 따로 만들어요. 복사 버튼으로 붙여 넣을 수 있고, 지난 기록에도 함께 보관돼요.

## 설교 패턴 학습
최종 정리를 할 때마다 다음이 자동으로 진행돼요.
1. 받아쓰기의 시간 표시·출처 줄과 겹쳐 붙은 중복 문장을 걷어냅니다.
2. 설교자의 지난 패턴(시작·끝 신호, 대지 전환 말, 예화·적용·마무리 방식, 자주 틀리는 용어)을 정리 지시에 넣습니다.
3. 이번 설교에서 새로 본 패턴과 용어 교정을 설교자별로 쌓아 휴대폰과 드라이브 `말씀 정리/설교 분석/설교패턴_<설교자>.json`에 저장합니다.
4. 쌓인 용어 교정은 다음 받아쓰기에도 쓰입니다.
설교자 이름 뒤의 '목사', '목사님' 같은 호칭은 같은 사람으로 봅니다. 지난 기록 → '학습된 설교 패턴 보기'에서 내용을 볼 수 있어요.

## 파일
- `index.html`, `style.css`: 화면
- `app.js`: 녹음, 대기열, 화면 상태
- `gemini.js`: Gemini 호출과 프롬프트
- `pdf.js`: 페이지 나누기와 PDF 만들기
- `drive.js`: 구글 로그인과 드라이브·시트 저장
- `learn.js`: 설교 패턴 학습과 받아쓰기 잡음 정리
- `profiles/<설교자>.json`: 받아쓰기를 직접 분석해 넣은 설교자별 기본 패턴
- `markup.js`: `[[g|...]]` 같은 색깔 표시 문법 처리
- `demo.json`: `?demo=1`로 여는 샘플

## 개인정보
- Gemini API 키는 휴대폰 브라우저 안(localStorage)에만 저장되며 저장소에 들어가지 않습니다.
- 구글 권한은 `drive.file`만 써서, 이 앱이 만든 파일과 폴더에만 접근합니다.
